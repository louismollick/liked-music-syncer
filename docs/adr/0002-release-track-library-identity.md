# Use release tracks for library identity

The Library identifies a song's appearance on a Release by trusted release ID, disc number, and track number. A source video ID describes the Recording and may repeat across album, single, EP, and reissue Release Tracks. This keeps release-specific metadata and artwork separate while still allowing the app to recognize that several Release Tracks use the same Recording. Remote reconciliation matches the local relative path and never chooses a destination from recording identity alone.
